# Hanzala Malik — Futuristic AI/ML & Data Science Portfolio

A state-of-the-art, interactive portfolio web application built with React 18, Vite, and custom Neural Glassmorphism styling. Configured for instantaneous zero-config deployment on **GitHub Pages**.

## Live Architecture Features

- **Interactive Synaptic Canvas**: GPU-accelerated neural constellation connecting nodes based on mouse proximity.
- **Interactive AI Shell / Terminal**: Built-in bash-like command shell allowing visitors to query live system specs, projects, and contact channels.
- **Categorized Project Hub**: Showcases live GitHub repositories (SkinVision AI, Habitat Multi-Agent Consultant, Facial Emotion Recognition research, and YOLOv8 Surveillance).
- **Interactive Experience Matrix**: Detailed breakdown of industry impact at Cnergyico, Escaplix, CloudOps, and NADRA.
- **Skills Neural Matrix**: Complete breakdown of Computer Vision, Speech/ASR, Multi-Agent systems, and Data Engineering tools.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized static build will be placed in `dist/`.

## Deploying to GitHub Pages

1. Push this project to your GitHub repository (e.g. `https://github.com/Hanzala007-code/hanzala-portfolio`).
2. Go to **Settings > Pages** on GitHub.
3. Under **Build and deployment**, select **GitHub Actions** (or deploy the `dist/` folder via the `gh-pages` branch).
